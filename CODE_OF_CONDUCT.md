# Codigo de Conduta

Este projeto deve ser um espaco respeitoso, pratico e acolhedor.

## Esperado

- Seja gentil e claro.
- Critique ideias e codigo, nao pessoas.
- Explique problemas com contexto suficiente.
- Ajude iniciantes a entenderem o caminho.

## Nao aceito

- Ataques pessoais.
- Assedio.
- Linguagem discriminatoria.
- Exposicao de dados privados.

Problemas podem ser reportados abrindo uma issue ou entrando em contato com o mantenedor.
