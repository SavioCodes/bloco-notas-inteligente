# Bloco de Notas Inteligente v0.1.1

Release focada em empacotamento Windows e validacao do fluxo principal.

## Destaques

- Adicionado executavel Windows `BlocoNotasInteligente.exe`.
- Adicionado smoke test automatizado do fluxo de usuario.
- Adicionado comando `--version`.
- Adicionado comando `--smoke-test`.
- Adicionado script `scripts/build_windows.ps1`.
- Adicionada documentacao de empacotamento Windows.
- Adicionado hash SHA256 junto ao executavel.

## Fluxo validado

- Criar nota.
- Salvar nota.
- Buscar nota.
- Mover nota para lixeira.
- Restaurar nota.
- Exportar nota em Markdown.
