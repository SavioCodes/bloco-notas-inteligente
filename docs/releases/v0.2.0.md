# Bloco de Notas Inteligente v0.2.0

Release com recursos de produtividade e seguranca local.

## Destaques

- Preview Markdown formatado.
- Backup automatico do banco SQLite.
- Backup manual pelo menu e atalho.
- Temas `Papel/caderno`, `Claro` e `Escuro`.
- Protecao opcional por senha.
- Smoke test expandido cobrindo fluxo completo de usuario.
- Novos testes para Markdown, backup, criptografia e banco.

## Atalhos novos

```text
Ctrl+P - mostrar/ocultar preview Markdown
Ctrl+B - criar backup agora
```

## Protecao por senha

A protecao por senha criptografa localmente titulo, conteudo e tags. Antes de
ativar ou desativar essa protecao, o app cria um backup do SQLite.

Observacao: esta e uma protecao local inicial. Para dados extremamente sensiveis,
use tambem criptografia de disco auditada.
