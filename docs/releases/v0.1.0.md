# Bloco de Notas Inteligente v0.1.0

Primeira release publica do projeto.

## Destaques

- App desktop para Windows e Linux.
- Interface reorganizada com tema visual, paineis e atalhos.
- Salvamento local em SQLite.
- Busca por titulo, conteudo e tags.
- Painel inteligente local com resumo, palavras-chave, tags sugeridas e tarefas.
- Lixeira recuperavel com restauracao.
- Importacao de `.txt` e `.md`.
- Exportacao Markdown.
- Testes automatizados e workflows de CI.

## Como executar no Windows

Clique duas vezes em:

```text
Abrir-Bloco-de-Notas.bat
```

Para verificar a instalacao:

```text
Testar-Instalacao.bat
```

## Como executar no Linux

```bash
chmod +x scripts/run.sh
./scripts/run.sh
```

## Observacao

Esta release ainda e uma base inicial. Os proximos passos recomendados sao
preview Markdown, backup automatico, empacotamento e criptografia opcional.
